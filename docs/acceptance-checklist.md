## 扫描、评分与证据

- [x] 扫描前展示当前可用数据源、真实/模拟标签、1 至 3 次重复采样和预计额度消耗。

- [x] 扫描前原子扣减额度；并发请求不会把额度扣成负数；执行失败退还本次额度。

## 抢位机会与增长实验

- [x] 每次完成扫描后，以“问题 × 平台”生成提及缺口、竞品优势、引用缺口和品牌风险机会，并保存对应原始证据。
- [x] 同一机会最多创建一个增长实验，实验保存基线扫描、假设、行动计划和目标 URL。
- [x] 实验状态按 `DRAFT → ACTIVE → VERIFYING → VERIFIED/INCONCLUSIVE` 流转，对应“行动草案、行动执行中、正在验证、已验证提升、结果待观察”。
- [x] 发布或更新行动只保存行动版本和最早复查时间，不会自动安排或启动复扫。
- [x] 用户必须点击“开始验证”或“恢复验证”才能执行复扫；模拟实验可立即手动验证，真实实验在 7 天观察窗口到期前不能验证。
- [x] 验证复用基线问题版本、数据源和重复次数，并要求相同评分算法版本和当前行动版本。
- [x] 验证中断后可安全恢复；并发触发不会重复创建有效复扫、重复扣额度或重复结算。
- [x] 结果保存 GeoScore、提及率、推荐率和引用率差值；未达到规则时如实标记“结果待观察”。
- [x] 实验可回到基线与复扫报告，结果不宣传为严格因果关系或排名保证。
